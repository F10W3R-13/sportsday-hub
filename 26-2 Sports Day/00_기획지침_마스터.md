이 지침서는 살아있는 문서(living document)입니다. 업무 진행에 따라 아래 규칙으로 갱신합니다.

### 갱신 규칙
1. **매 업무 완료 시**: 해당 항목 `[ ]` → `[x]` 로 체크
2. **결정 확정 시**: `3. 핵심 결정 추적표`의 상태를 🔴→🟢로 변경, 결정일 기입
3. **새 이슈 발생 시**: 관련 팀 지침의 "이슈 로그"에 추가
4. **정기 갱신**: 최상단 `최종 갱신일` 업데이트

### 파일 구조
```
26-2 Sports Day/
├── 00_기획지침_마스터.md          ← 본 파일 (전체 현황/결정/일정)
├── 컨텐츠팀/
│   └── 컨텐츠팀_지침.md            ← 게임 구성·규칙·배치도
├── 예산팀/
│   └── 예산팀_지침.md              ← 예산·입장료·준비물
├── 교환담당팀/
│   └── 교환담당팀_지침.md          ← 구글폼·명단·팀 배정
└── 타임라인_인원관리팀/
    └── 타임라인_인원관리팀_지침.md  ← 타임라인·하클 배치·버스
```

### 갱신 예시
```
[변경 전] | D1 | 컨셉/행사명 | 인사이드아웃 / ... | 🔴 미정 | - | 1차 회의 검토 |
[변경 후] | D1 | 컨셉/행사명 | 인사이드아웃 | 🟢 확정: "HI-Side Out" | 8/9 | 2차 회의 확정 |
```
