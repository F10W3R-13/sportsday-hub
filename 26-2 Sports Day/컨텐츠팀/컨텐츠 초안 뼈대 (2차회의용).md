# 컨텐츠 초안 뼈대 — 2차 회의 참고 자료 (컨텐츠팀용)

> 📌 이 자료는 컨텐츠팀 톡방에서 논의하실 때 **참고**하시라고 정리한 뼈대입니다.
> 작년(26-1 마리오) 게임 구성을 **인사이드아웃 6팀**에 맞춰 변형한 방향 제안이며,
> 팀에서 논의 후 수정·확정하시면 됩니다. "이대로 하라"가 아닙니다.
>
> 💡 **8/9 2차 회의는 "중간 방향 점검"**입니다. 세부 규칙까지 완성할 필요는 없고,
> **"어떤 게임 할지, 어떤 방향으로 갈지"** 정도의 뼈대를 가져오시면 됩니다.
> 상세 규칙·물품 리스트는 8/16(컨텐츠 완성)까지 마무리합니다.

**최종 갱신일**: 2026-08-05
**기준**: 인사이드아웃 / 6팀 (Joy · Sadness · Anger · Disgust · Fear · Anxiety)

---

## 0. 전체 구성 (가이드라인 요구)

| 구분 | 개수 | 참여 방식 |
|---|---|---|
| 토너먼트 게임 | 4종 | 팀별 일부 인원 (부전승 공식화) |
| 메인 게임 | 2종 | 전원 참여 (1부·2부에 1종씩) |
| 미니게임 | 6종 | 자유 부스 (도장 투어) |

> ⚠️ 6팀이므로 토너먼트 대진: 6팀 → 부전승 2팀 + 경기 4팀(2경기) 구조
> 작년(5팀)은 부전승 1팀 + 경기 4팀(2경기) → 부전승 혜택이 2팀으로 늘어남 (공평성 공지 필수)

## 1. 토너먼트 게임 4종 (초안)

> 작년 26-1 게임을 기본 유지하되, 인사이드아웃 감정 컨셉을 각색.
>
> 📌 **회의에서 다루는 것 (🟡 방향)**: 4종이 "어느 게임들인지" 후보 확인
> ⚪ **회의에서 안 함**: 출전인원 상세, 물품 수량, 시간 설계, 캐릭터 매핑
>    (아래 표는 8/16 컨텐츠 완성 작업의 씨앗으로 보존. 회의에서 디테일을 파고들지 않습니다)

### 1) 🟡 기억 판 뒤집기 (구 코인 뒤집기)
| 항목 | 내용 |
|---|---|
| 컨셉 | 각 면에 6가지 감정 캐릭터 도안 부착. "기억 구슬을 차지하라!" |
| 출전 | 팀당 6명 (성별 무관) |
| 규칙 | 3분간 상대 판을 뒤집어 내 팀 색으로. **홀수 세팅(무승부 방지)** |
| 소요 | 경기 1분 + 준비 5분 |
| 물품 | 양면 색깔 판 (홀수, 예: 35~41장) |
| 작년 차이 | 5팀→6팀, 마리오 코인→감정 캐릭터 도안 |

### 2) 🌸 무궁화꽃이 피었습니다
| 항목 | 내용 |
|---|---|
| 컨셉 | 술래 = Anger(빨강) 캐릭터 복장. 뒤돌 때 감정 폭발 컨셉 |
| 출전 | 팀당 전원 |
| 규칙 | 술래 구호(엇박), 뒤돌면 정지, 움직이면 **뿅망치** 터치(물총 X - 작년 피드백) |
| 소요 | 라운드 1분 + 준비 5분 |
| 물품 | 뿅망치 2+, 술래 복장 1, 마이크, 콘 |
| 비고 | 작년 피드백: "물총 조준 애매 → 뿅망치 추천" 반영 |

### 3) 💪 줄다리기
| 항목 | 내용 |
|---|---|
| 컨셉 | 줄 중앙에 "기억 구슬" 마커. "감정을 우리 팀으로!" |
| 출전 | 팀당 12명 (남6/여6) — **성비 필수** (구글폼 성별 수집 연동) |
| 규칙 | **30초 제한** (부상 방지 - 작년와 동일). 마커 위치로 승패 |
| 소요 | 경기 1분 + 준비 5분 |
| 물품 | 밧줄 1, 마커 1, **목장갑 팀당 12켤레** (안전) |

### 4) 🏀 단체 피구
| 항목 | 내용 |
|---|---|
| 컨셉 | 피구공 = Fear(보라) 캐릭터. 공에 맞으면 "겁에 질려 아웃" |
| 출전 | 팀당 12명 (성별 무관) |
| 규칙 | 8분 제한, 생존자 많은 팀 승. **피치 공주 룰** → 인사이드아웃: "주인공(Joy) 룰" (Joy 1명 아웃 시 팀 패배) |
| 소요 | 경기 8분 + 준비 5분 |
| 물품 | 피구공 1, Joy 표식(왕관/머리띠) 1개/팀 |

## 2. 메인 게임 2종 (초안)

> 📌 **회의에서 다루는 것 (🟡 방향)**: 2종이 "어느 게임들인지" 후보 확인
> ⚪ **회의에서 안 함**: 출전인원 상세, 물품 수량, 시간 설계, 캐릭터 매핑

### 1) 🎮 짝 찾기 게임 (1부 메인) — 전원 참여
| 항목 | 내용 |
|---|---|
| 컨셉 | "감정의 짝을 찾아라" — 음악 중 이동, 숫자 외치면 원형 진형 |
| 출전 | 교환학생 전원 |
| 규칙 | 같은 팀끼리만 모이면 탈락 (2개 팀 이상 혼합 필수). 4회 호명 후 생존자 수 집계 |
| 소요 | 룰 설명 5분 + 본게임 10분 = 약 20분 |
| 물품 | 마이크, 팀별 조끼/두건, BGM |

### 2) 🏁 혼성 계주 (2부 메인) — 6팀 + 하클팀
| 항목 | 내용 |
|---|---|
| 컨셉 | 바통 = 감정 구슬 모양 소품. "감정을 이어 달려라!" |
| 출전 | 팀당 6명(여3/남3) → **하클팀 포함 7팀 동시 출발** |
| 규칙 | 여→남 순서 반 바퀴 릴레이. 하클 이기면 **추가 10점** |
| 소요 | 10~20분 |
| 물품 | 바통 7개(감정구슬 모양), 트랙 콘 30+, 결승 테이프 1 |
| 비고 | 작년 호평: "계주 하클팀 따로 한 점 좋았다" → 유지 |

## 4. 점수배분 — 6팀 재설계 옵션 (논의용)

> 작년(5팀): 100 / 80 / 60 / 40 / 40
> 6팀은 격차를 촘촘히 해야 역전 드라마 가능.
>
> 📌 **회의에서 다루는 것 (🟡 방향)**: 점수 철학(완만 vs 가파름 vs 등간격)만 논의
> ⚪ **회의에서 안 함**: 구체 점수 확정 (8/16 컨텐츠 완성 후)

| 순위 | 작년(5팀) | 옵션A (완만) | 옵션B (가파름) | 옵션C (등간격) |
|---|---|---|---|---|
| 1위 | 100 | 100 | 100 | 100 |
| 2위 | 80 | 85 | 90 | 85 |
| 3위 | 60 | 70 | 75 | 70 |
| 4위 | 40 | 55 | 55 | 55 |
| 5위 | 40 | 40 | 35 | 40 |
| 6위 | - | 30 | 20 | 25 |

- **옵션A(완만)**: 중위권 경쟁 유도, 역전 가능성 ↑
- **옵션B(가파름)**: 상위권 독주 방지 강하게
- **옵션C(등간격)**: 단순·계산 쉬움

> 부전승 팀(2팀)은 최소 5위 점수(옵션A 기준 40점) 보장
> ⚠️ 추천 마크 없음 — 세 옵션 모두 동등한 후보. 회의에서 철학을 먼저 잡고, 구체 점수는 8/16 이후 확정.
