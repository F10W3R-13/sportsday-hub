# 05. 드라이브 연동 (선택)

각 팀의 구글 드라이브 폴더에 올라온 파일을 허브 대시보드에서 보여주는 기능.
연초 1회 설정하면 시즌 내내 자동.

## 1. Google Cloud Console 에서 OAuth 클라이언트 만들기

1. https://console.cloud.google.com — 프로젝트 생성 (예: `sportsday-hub-27`)
2. API 및 서비스 → 라이브러리 → **Google Drive API** 사용 설정
3. OAuth 동의 화면: External 로 만들고 스프 범위에
   `https://www.googleapis.com/auth/drive.readonly` 추가. 테스트 사용자에 쓸 계정 추가.
   (앱이 미공개 테스트 상태여도 우리끼리 쓰기엔 충분)
4. 사용자 인증 정보 → 사용자 인증 정보 만들기 → **OAuth 클라이언트 ID**
   - 유형: 웹 애플리케이션
   - 승인된 리디렉션 URI: `https://<배포주소>/api/auth/google-callback`
     (로컬 테스트 시 `http://localhost:3000/api/auth/google-callback` 도 추가)
5. 생성된 **클라이언트 ID / 시크릿** 확보 (시크릿은 절대 git에 커밋 금지 —
   다운로드 JSON이 `client_secret_*.json` 이름이면 .gitignore가 막아준다)

## 2. 환경변수

`.env.local`과 Vercel 양쪽에:

```
GOOGLE_CLIENT_ID=...
GOOGLE_CLIENT_SECRET=...
DRIVE_ENCRYPTION_KEY=<64자리 hex — 아래 생성법>
GOOGLE_OAUTH_REDIRECT_URL=https://<배포주소>/api/auth/google-callback
SUPABASE_SERVICE_ROLE_KEY=...
DRIVE_ROOT_FOLDER_ID=<올해 기획 루트 폴더 ID>
```

DRIVE_ENCRYPTION_KEY 생성:
```
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
```
⚠ 한 번 정하면 변경 금지 — 바꾸면 저장된 토큰 복호화 불가(재연결하면 되지만 번거로움).

## 3. 연결

1. 허브 → **설정** 페이지 → "구글 드라이브 연결" → 구글 로그인·승인
2. 팀 폴더 매핑: 자동 매칭(DRIVE_ROOT_FOLDER_ID 하위에서 팀명 검색) 또는 팀별 폴더 ID 수동 입력
3. "지금 동기화" → 대시본의 전체 팀 파일 피드 확인

## 폴더 ID 구하는 법

드라이브에서 폴더 열 때 URL 끝 `/folders/` 뒤의 문자열.

## 작년 운영 방식

파일은 각 팀이 자기 폴더에 올리고, 허브가 최신순으로 보여준다. 26-2에서
드라이브→로컬 자동 다운로드봇·카톡 발송봇도 운영했으나 2026-09-18 전면 철폐
(운영 부담 대비 효과 미미). 파일 확인은 허브에서, 백업은 수동.
