# 세션 요약 — 카카오톡 단체방 체크리스트 자동 발송 기능

> 날짜: 2026-08-21
> 프로젝트: sportsday-hub (Next.js 16 + Supabase + Vercel)

## 목표

웹앱의 긴급 체크리스트를 **기존 일반 카카오톡 단체방**("26-2 스포츠데이 기획팀")에 매일 자동 발송해 팀원들에게 그날 업무를 상기시키는 기능.

## 배경 및 방법 결정 과정

- 일반 단체 채팅방은 **공식 API가 없음** → 어떤 방식이든 비공식(약관 위반) 경로 필요
- 알림톡(사업자 필요), 채널, 비공식 라이브러리(node-kakao, 정지 위험 높음), 안드로이드 매크로 검토
- 여분 폰이 없어서 최종 선택: **PC 카카오톡 UI 자동화(PyAutoGUI)** — 계정 정지 위험이 상대적으로 낮고 기존 단체방 그대로 사용 가능

## 구현 내용

### 1. 다이제스트 빌더 확장 — `lib/kakao-digest.ts`
- 미완료 체크리스트 항목(`checklist_items`) 중 연결 마일스톤이 D-3 이내(지연 포함)인 것을 포함
- **마일스톤에 미완료 체크리스트가 붙으면 마일스톤 줄은 생략**(체크리스트 기준 표시, 중복 방지)
- 스타일 옵션 추가:
  - `compact` (기본): 카카오 메모 200자 제한용 요약 나열 — 기존 "나에게 보내기" 크론은 유지
  - `detailed` (단체방용): 제목·팀명 잘라내기 없음, `[기한 지연 (D+2)]` / `[오늘 마감]` 설명형 라벨, 담당 팀 별도 줄
- `textLimit`, `maxItems` 옵션화
- 테스트 12개 통과 (`tests/kakao-digest.test.ts`)

### 2. 신규 API — `app/api/digest/today/route.ts`
- PC 스크립트가 오늘의 detailed 다이제스트를 JSON으로 받는 GET 엔드포인트
- `CRON_SECRET` Bearer 인증 (기존 크론과 동일)
- 임박 항목 없으면 `{"text": null}` 반환 → 스크립트가 전송 생략

### 3. PC 전송 스크립트 — `scripts/kakao_group_sender.py`
- API에서 다이제스트 fetch → PyAutoGUI로 PC 카카오톡 조작(Ctrl+F 검색 → 방 진입 → 클립보드 붙여넣기 → 전송)
- 설정: 환경변수 `DIGEST_API_URL`, `CRON_SECRET`, `KAKAO_ROOM_NAME`

### 4. 기존 크론 수정 — `app/api/cron/kakao-digest/route.ts`
- "나에게 보내기" 다이제스트에도 체크리스트 포함

## 배포 (Vercel)

- 트러블슈팅 기록:

  - pulled `CRON_SECRET`이 실제 배포 값과 불일치 → **새 시크릿으로 교체 후 재배포**
  - stale 프로덕션 별칭이 404 반환 → 새 커밋 푸시로 새 배포 붙여 해결
- 로컬 `next build && next start`로 코드 정상 여부 먼저 검증한 후 배포 문제임을 특정
- 최종: `/api/digest/today` → 200, 실제 단체방 전송 테스트 성공

## 자동화 등록 (Windows 작업 스케줄러)

- 작업명: `KakaoChecklistDigest`, **매일 18:00**
- 설정: `WakeToRun`(절전에서 자동 깨움), `StartWhenAvailable`(놓친 작업은 PC 켜질 때 실행), 배터리 허용
- 사용자 환경변수 등록 완료: `KAKAO_ROOM_NAME`, `CRON_SECRET`, `DIGEST_API_URL`
- 수동 테스트: `Start-ScheduledTask -TaskName "KakaoChecklistDigest"`
