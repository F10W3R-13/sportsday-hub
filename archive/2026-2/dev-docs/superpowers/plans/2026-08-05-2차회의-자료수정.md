# 26-2 스포츠데이 2차 회의 자료 수정 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 26-2 기획팀 2차 회의(8/9) 자료 5개를 "방향 점검 + 3단 분류(🟢확정/🟡방향/⚪보류)" 원칙으로 일관되게 재정렬하여, 동상이몽 회의가 되는 구조적 원인을 제거한다.

**Architecture:** 5개 문서를 3단 분류 SSOT(single source of truth) 아래로 정렬. 수정 순서는 의존도가 낮은 것(독립적 마스터지침)부터 높은 것(안건서) 순으로 진행하여, 각 태스크가 직전 태스크에 의존하지 않도록 한다.

**Tech Stack:** Markdown only. 수정 도구 = Edit tool (exact string replacement).

## Global Constraints

- **문서는 in-place 수정만** (신규 파일 생성 없음)
- **3단 분류 기호 통일**: 🟢 확정 / 🟡 방향 / ⚪ 보류 (다른 기호 사용 금지)
- **행사명 = HI-Side Out** (모든 문서에서 이 값으로 통일)
- **팀명 = Joy / Sadness / Anger / Disgust / Fear / Anxiety** (6개, 순서 보존)
- **"디테일은 보존"**: 게임 물품수량·시간·캐릭터매핑 등은 삭제하지 않고 분류 배지만 추가 (8/16 컨텐츠 완성 작업의 씨앗)
- **이모지·표 형식 유지**: 기존 문서의 markdown 스타일(emoji, table)을 깨지 않게 할 것
- **범위 밖**: 기획 일정 xlsx ↔ 마스터지침 날짜 정합화, 사전 크로스팀 인계 일정 — 본 계획에서 다루지 않음
