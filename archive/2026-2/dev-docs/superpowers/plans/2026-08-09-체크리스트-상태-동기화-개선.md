# 체크리스트 상태 동기화 개선 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 체크리스트/마일스톤 체크 상태가 여러 화면·탭에 걸쳐 일관되게 동기화되도록 한다 — 진행률 계산 통일, 낙관적 UI 롤백, 교차 탭 동기화.

**Architecture:** 진행률 계산을 단일 순수 함수(`computeProgress`)로 중앙화하여 3개 화면이 같은 기준(체크리스트만)을 공유. 체크박스 컴포넌트에 `onError` 원복 추가로 실패 시 UI 정합성 확보. `BroadcastChannel` 래퍼로 동일 출처 탭 간 변경 전파. DB 스키마/RLS/트리거는 변경 없음.

**Tech Stack:** Next.js 16 (App Router), React 19, TanStack React Query 5, Supabase (PostgreSQL), Vitest 4 (node environment), TypeScript.

## Global Constraints

- **테스트 환경**: Vitest, `environment: 'node'`, `include: ['tests/**/*.test.ts']`. React Testing Library 미사용 — 순수 함수만 단위 테스트. 컴포넌트는 `pnpm typecheck` + `pnpm lint` + 수동 검증.
- **경로 별칭**: `@` → 프로젝트 루트(`sportsday-hub/`). 예: `@/lib/progress` → `sportsday-hub/lib/progress.ts`.
- **파일 구조 관례**: 카테고리 디렉토리(`lib/mutations/`, `lib/queries/`) 또는 평면 도메인 파일(`lib/utils.ts`). `lib/utils.ts` 평면 파일이 이미 존재하므로 `lib/utils/` 디렉토리를 만들지 않는다(섀도잉 혼란 방지). 신규 유틸은 평면 도메인 파일로 둔다.
- **커밋 메시지**: 한국어, conventional 접두어(`feat:`, `refactor:`, `fix:` 등). 기존 커밋 스타일 준수.
- **진행률 기준**: `checklist_items` 항목만. 마일스톤 자체 `completed`는 진행률에서 제외(별개 표시).
- **데이터 모델 변경 금지**: 스키마·RLS·감사 트리거·시드 데이터는 건드리지 않는다.

```ts
import type { ChecklistItem } from '@/lib/types/models'

export interface Progress {
  completed: number
  total: number
  percent: number
}

/**
 * 진행률의 단일 출처.
 * checklist_items만을 기준으로 계산한다.
 * 마일스톤 자체의 completed는 별개 표시지, 진행률에 포함하지 않는다.
 */
export function computeProgress(items: ChecklistItem[]): Progress {
  const total = items.length
  const completed = items.filter((i) => i.completed).length
  const percent = total > 0 ? Math.round((completed / total) * 100) : 0
  return { completed, total, percent }
}
```

```tsx
export function EditableChecklistCheckbox({
  item,
}: {
  item: ChecklistItem
}) {
  const toggle = useToggleCheck()
  const [localChecked, setLocalChecked] = useState(item.completed)

  // item.completed가 외부에서 바뀌면(예: 다른 탭에서 변경) 로컬도 동기화
  useEffect(() => {

  const handleChange = () => {
    setLocalChecked(!localChecked) // 즉시 UI 반영 (낙관적)
    toggle.mutate(item, {
      onError: () => setLocalChecked(item.completed), // 실패 시 원복
    })
  }

  return (
    <Checkbox
      checked={localChecked}
      onCheckedChange={handleChange}
      disabled={toggle.isPending}
    />
  )
}
```

`sportsday-hub/lib/sync.ts` 생성:

```ts
const CHANNEL_NAME = 'sportsday-sync'

export type SyncMessage =
  | { type: 'checklist-updated' }
  | { type: 'milestone-updated' }

/**
 * 다른 탭에 상태 변경을 알린다.
 * SSR 환경(window 없음)이나 BroadcastChannel 미지원 브라우저는 no-op.
 * BroadcastChannel은 동일 탭의 송신을 자기 자신에게 전달하지 않는다(표준 동작).
 */
export function notifyTabs(msg: SyncMessage): void {
  if (typeof BroadcastChannel === 'undefined') return
  const ch = new BroadcastChannel(CHANNEL_NAME)
  ch.postMessage(msg)
  ch.close()
}

/**
 * 탭 동기화 메시지를 구독한다. 구독 해제 함수를 반환한다.
 * 미지원 환경은 더미 해제 함수를 반환하여 호출부가 방어 코드 없이 동작.
 */
export function onTabSync(handler: (msg: SyncMessage) => void): () => void {
  if (typeof BroadcastChannel === 'undefined') return () => {}
  const ch = new BroadcastChannel(CHANNEL_NAME)
  ch.onmessage = (e: MessageEvent<SyncMessage>) => handler(e.data)
  return () => ch.close()
}
```

```tsx
'use client'

import { useEffect } from 'react'
import { useQueryClient } from '@tanstack/react-query'
import { useRouter } from 'next/navigation'
import { onTabSync } from '@/lib/sync'
import { queryKeys } from '@/lib/queries/keys'

/**
 * 다른 탭에서 발생한 체크리스트/마일스톤 변경을 수신하여
 * 현재 탭의 캐시와 서버 데이터를 갱신한다.
 * Providers 아래에 마운트하여 모든 페이지에 적용.
 */
export function TabSyncListener() {
  const queryClient = useQueryClient()
  const router = useRouter()

  useEffect(() => {
    return onTabSync((msg) => {
      if (msg.type === 'checklist-updated') {
        queryClient.invalidateQueries({ queryKey: queryKeys.checklist })
        void router.refresh()
      }
      if (msg.type === 'milestone-updated') {
        queryClient.invalidateQueries({ queryKey: queryKeys.milestones })
        void router.refresh()
      }
    })
  }, [queryClient, router])

  return null
}
```
