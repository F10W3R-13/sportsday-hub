# 회고 / 교훈 (Lessons Learned)

세션별 회고와 개발 과정에서 얻은 교훈을 기록합니다.

## 목적

- 백엔드/데이터 설계 문제점 기록
- 사용자 병목 / UX 문제 기록
- 배포/프로세스 교훈 기록
- 자기 코드의 한계에 대한 솔직한 성찰
- 다음 세션 액션 아이템 추적

## 파일명 규칙

`YYYY-MM-DD-<주제>-회고.md`

날짜 + 세션의 핵심 주제 + `-회고` 접미사.

## 작성 구조 (권장)

1. **핵심 교훈 (한 줄)** — 세션의 단일 교훈
2. **백엔드/데이터 설계 문제점**
3. **사용자 병목 / UX 문제**
4. **배포/프로세스 교훈**
5. **내 코드의 한계 (솔직 회고)** — 자기 비판 포함
6. **다음 세션 액션 아이템** — 표 형태, 우선순위 표시
7. (선택) 세션 통계, 참고 파일
