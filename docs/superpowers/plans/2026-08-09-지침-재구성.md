# 팀 지침 재구성 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 5개 마크다운 지침(마스터 1 + 팀별 4)을 "원칙 카드" 방식으로 재작성하여 1,477줄 → ~385줄로 압축하고, 동적 상태·데이터는 웹앱/원본 소스로 이관한다.

**Architecture:** 지침 = 정적 원칙(원칙 카드)만. 결정/마일스톤/체크리스트/이슈/피드백/갱신가이드/실적데이터는 모두 제거하고 웹앱·원본 링크로 대체. 마이그레이션 재실행/스크립트 수정은 마일스톤 UI 작업 완료 후 별도 진행하므로 이 계획에서 제외.

**Tech Stack:** 마크다운 only (웹앱 코드 변경 없음)

## Global Constraints

스펙 `docs/superpowers/specs/2026-08-09-지침-재구성-design.md`의 전역 제약:
- **카드 포맷**: 각 원칙은 `## 🎯 [명제 제목]` + `**원칙.** [1문장]` + `왜: [1-2문장, 선택]` + `참고: [링크, 선택]` 구조
- **제목 = 명제** (명사구가 아닌 주장). 스캔만으로 핵심 전달
- **상태 금지**: 🟡/⚪, "8/9 회의", "8/16 완성" 등 시점 의존 표현 일절 사용 금지
- **체크리스트 박스 금지**: `[ ]` 문법 사용 안 함 (웹앱 checklist_items가 관리)
- **데이터 복사 금지**: 단가표/실적/양식 내용을 지침에 복사하지 않음. 원본 파일 상대경로 링크만
- **중복 금지**: 같은 설명(예: 템플릿 우선순위)을 여러 카드에 반복하지 않음. 마스터 전역 원칙 1개로 통합
- **링크 규칙**: 상대경로(지침 파일 위치 기준). 웹앱 참조는 `웹앱 결정 D4` 형태의 짧은 인라인 참조
- **카드 개수**: 마스터 5-7개 / 팀별 5-8개
- **두 소스 동기화**: `26-2 Sports Day/` (canonical) 와 `sportsday-hub/content-source/` (seed 소스) 내용 완전 일치
- **DB 미접근**: `migrate:md` 재실행 금지, `0005_seed_data.sql` 건드리지 않음 (UI 작업 완료 후 별도 진행)

## 🎯 전역 원칙

### 🎯 참고 템플릿: 25-2가 주, 26-1은 보조

**원칙.** 과거 실적·양식·배치는 **25-2(2025 가을, 율전)**를 1차 기준으로 삼고, **26-1(명륜)**은 단가 비교·운영 노하우 정도만 보조로 참고한다.

왜: 25-2만 이번과 같은 장소(율전)·같은 시기(9월)·같은 버스 구조(명륜→율전)로 이미 검증됐다. 26-1은 명륜이라 장소가 달라 배치·소요시간 기준이 되지 못한다.
참고: 25-2 자료는 `../25 스포츠데이 참고용 자료/`, 26-1은 `../26-1 Sports Day/`

### 🎯 식사는 비건 옵션이 필수

**원칙.** 점심은 일반 메뉴 + 비건 메뉴 최소 1종을 함께 제공한다.

왜: 교환학생 중 비건·할랄·알러지 식이가 항상 존재한다. 작년(25-2)에 비건 배송 지연 이슈가 있었으므로 시간 여유를 둬야 한다.
참고: 웹앱 결정 D5 / 25-2는 불고기버거(롯데리아) + 배지샐러드(서브웨이)

### 🎯 적자 구조를 전제로 기획한다

**원칙.** 이번 26-2는 단체티 신규 제작 + 천막 업체 대여로 25-2와 동일한 적자 구조다. 입장료 수입만으로 지출 충당이 안 되며, 동아리 보전을 전제로 기획한다.

왜: 25-2 실적 총지출 4,387,520원 vs 수입 1,500,000원 = 적자 475,320원(동아리 보전). 26-1 흑자(516,952원)는 단체티 재활용 + 국제처 천막 지원이라는 특수 케이스라 이번 기준이 안 된다.
참고: 웹앱 결정 D4 / [25-2 최종기획안 예산안](../25 스포츠데이 참고용 자료/[2025_Fall_Sports Day] 최종기획안 및 인원관리표.xlsx)

### 🎯 과거 망고(실수)는 웹앱 피드백 체크리스트로 추적

**원칙.** 작년 피드백 반영 사항은 각 팀 지침이 아니라 **웹앱의 '피드백 체크리스트'**에서 팀별로 관리한다.

왜: 지침에 박아두면 해결돼도 계속 남아있어 혼란을 준다. 웹앱은 체크박스로 완료 처리할 수 있어 상태가 정확하다.
참고: 웹앱 > 체크리스트 > feedback 섹션

### 🎯 지침은 원칙만, 상태는 웹앱에

**원칙.** 이 지침 문서엔 영구적인 원칙만 둔다. 결정·일정·진행·이슈·체크리스트는 모두 웹앱에서 관리한다.

## 🎯 원칙

### 🎯 게임 뼈대는 25-2(율전) 세트, 그 위에 인사이드아웃 컨셉 입히기

**원칙.** 토너먼트·메인·미니 게임의 **종목 자체는 25-2 율전 세트를 베이스로 유지**하고, 네이밍·소품·진행 멘트에 인사이드아웃 감정 테마(Joy/Sadness/Anger/Disgust/Fear/Anxiety)를 입혀 각색한다.

왜: 게임 종목 구성은 25-2가 같은 장소(율전)에서 검증됐다. 컨셉은 스킨으로 씌우면 되므로 종목 뼈대를 흔들 필요가 없다.
참고: [25-2 게임 구성 및 규칙](../25 스포츠데이 참고용 자료/[2025_Fall_Sports Day] 게임 구성 및 규칙.docx)

### 🎯 구성: 토너먼트 4·메인 2·미니 6 (불변 뼈대)

**원칙.** 게임 구성은 **토너먼트 4종**(팀별 일부 인원) + **메인 2종**(전원 경기, 1부·2부에 1종씩) + **미니 6종**(자유 부스 도장 투어, 1부 3종/2부 3종)이다.

왜: 이 구성은 25-2 검증값이자 행사 시간 배분의 뼈다귀. 팀 수(6)가 바뀌어도 종목 수 구성은 유지한다.

### 🎯 부전승은 공식화 + 매 경기 대진 추첨으로 혜택 분산

**원칙.** 부전승 팀은 별도 패널티 없이 다음 라운드 진출(최소 3위 점수 보장)로 **공식화**하고, 매 경기 **대진 추첨(제비뽑기)**으로 부전승 혜택이 특정 팀에 쏠리지 않게 분산한다.

왜: 6팀 체계에서 부전승은 불가피하다. 공식화하지 않으면 논란이 발생하고, 추첨 분산이 공정성 확보의 최소 조건이다.

### 🎯 점수 배분은 팀 수(D2)에 맞춰 재설계

**원칙.** 토너먼트·메인 점수 배분표는 확정된 팀 수(6팀)에 맞춰 재설계한다. 꼴등(6위)에는 최소 보장 점수를 부여한다.

왜: 25-2는 5팀 기준(100/80/60/40/40)이라 6팀에 그대로 적용할 수 없다. 6팀 전환 설계(토너먼트 100/85/70/55/40/40, 메인 100/85/70/55/40/20)를 출발점으로 삼는다.
참고: 웹앱 결정 D2(팀 개수) / D7(점수 배분)

### 🎯 심판 규칙은 문서화 + 3일 전 배정 + 오프라인 리허설

**원칙.** 각 게임 규칙을 문서화하고, 심판 배정은 **행사 최소 3일 전**에 완료하며, **오프라인 사전 리허설**을 진행한다.

왜: 작년 심판 숙지 부족 피드백(HIGH 우선순위). 공정성과 진행 속도 양쪽 모두에 필수적이다.

### 🎯 토너먼트를 1부·2부에 균형 배분

**원칙.** 토너먼트 종목(줄다리기·피구·계주 등 인기 종목)이 1부나 2부 한쪽에 몰리지 않도록 양쪽에 균형 있게 배분한다.

왜: 작년(26-1) 2부 미니게임이 한산했던 피드백(MID). 인기 종목 편중은 관람·참여 불균형을 낳는다.

### 🎯 배치도는 25-2 율전(60m×40m) 템플릿 기준

**원칙.** 행사 배치도는 **25-2 율전 대운동장(60m×40m, 콘 구역 표시) 템플릿**을 기준으로 작성하고, 팀 천막만 5→6으로 조정한다.

왜: 같은 장소(율전)의 검증된 배치. 26-1(명륜) 배치도는 장소가 달라 직접 기준이 되지 못한다.
참고: [25-2 배치도 PPT](../25 스포츠데이 참고용 자료/스포츠데이 배치도.pptx)
