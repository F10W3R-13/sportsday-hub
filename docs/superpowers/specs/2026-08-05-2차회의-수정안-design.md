## 0. 배경 — 왜 수정이 필요한가

### 0-1. 진단된 핵심 문제

26-2 기획팀은 25-2 흐름을 기준으로 "8/9 2차 회의 = 중간 방향 점검"으로 성격을 재조정했다(마스터지침 4-1). 이 결정 자체는 합리적이나, **문서와 자료·안건이 그 결정을 따라가지 못해** 세 가지 계층의 어긋남이 발생했다.

| 계층 | 문제 | 증상 |
|---|---|---|
| **문서 간 모순** | 확정 여부가 문서마다 다름 | 행사명·팀명이 D1/D3는 "미정/검토", 안건서·안내문은 "확정" |
| **준비 자료의 층 혼재** | "방향"과 "디테일"이 한 데 섞임 | 컨텐츠 뼈대에 물품 수량·시간·캐릭터 매핑까지; 점수배분에 ⭐(추천) 표시 |
| **안건의 직관성 부족** | 결정/논의/보류 구분 없음, 팀별 사일로 | "오늘 뭘 결정하나" 불명확; 발표 시간은 보고에만 소비 |

이 상태로 회의에 들어가면 참석자 각자가 다른 전제로 발표를 듣고 다른 것에 동의하는 **동상이몽 회의**가 될 구조적 위험이 있다.

### 0-2. 25-2와의 구조적 차이 (정당화된 조정)

| | 25-2 (율전, 9/20) | 26-2 (율전, 9/19) |
|---|---|---|
| 2차 회의 일시 | 3/31 (행사 173일 전) | 8/9 (행사 41일 전) |
| 2차 때 콘텐츠 상태 | **컨셉 결정 + 종목 확정** (결정 회의) | "방향 점검" (종목 확정은 8/16 이후) |
| 회의 자료 수준 | 게임 구성 docx = ①출전인원 ②진행방식 ③예상시간 ④심판구성 + 예외처리까지 갖춘 실행 설계서 | "어떤 게임 할지 후보" 수준 |

26-2가 "방향 점검"으로 간 것은 시점 차이 때문에 **정당**하다. 수정의 과제는 "이 결정을 문서 전체에 일관되게 관통시키는 것"이다.

## 1. 설계 원칙 — 3단 분류를 단일 진실 원천(SSOT)으로

회의에 참석하는 누구나 "오늘 이 항목이 어느 단계인가"를 한눈에 알 수 있어야 한다. 모든 수정 문서(안건서·안내문·뼈대·예산옵션·마스터지침)가 동일한 3단 분류를 공유한다.

```
🟢 1단: 확정 (CONFIRM)    → 확인만. 발표·논의 없음. (1분 컷)
🟡 2단: 방향 논의 (DISCUSS) → 옵션/철학을 잡는다. 결정은 8/16 이후.
⚪ 3단: 보류 (DEFER)      → 듣고만. 상세 규칙·물품·배치도·구글폼.
```

### 1-1. 항목별 분류 (수정의 기준표)

| 항목 | 분류 | 근거 |
|---|---|---|
| 컨셉(인사이드아웃) | 🟢 확정 | 확인만 |
| 팀 개수(6팀) | 🟢 확정 | 확인만 |
| 행사명(HI-Side Out) | 🟢 확정 | 확인만 |
| 팀명·컬러(Joy 등 6개) | 🟢 확정 | 확인만 |
| 게임 12종 선종 | 🟡 방향 | "어느 게임들로 가자" 후보만, 상세규칙은 8/16 |
| 점수배분 철학 | 🟡 방향 | 완만/가파름/등간격 — 철학만, 구체 점수는 8/16 |
| 입장료 | 🟡 방향 | 동아리 보전 한도 확인 전이므로 방향만 |
| 점심 메뉴 | 🟡 방향 | 비건 대응 등 철학만, 수량은 구글폼 후 |
| 단체티 방침 | 🟡 방향 | 재활용/신규/절충 — 방향만 |
| 잔여 마리오 티 수량 | 🟢 사전 확인(팩트) | 회의 전 브룸 재고 조사 |
| 게임 상세규칙·물품·시간 | ⚪ 보류 | 8/16 컨텐츠 완성 때 |
| 배치도 | ⚪ 보류 | 게임 확정 후 |
| 예산 시뮬레이션(단가·총액) | ⚪ 보류 | 8/16 이후, 예산팀 내부 참고용 |
| 교환 구글폼 진행 | ⚪ 보고만 | 일정 진행 중 |

## 2. 회의 재설계 — "확정된 전제 위에서 방향을 잡는 회의"

### 2-1. 회의 성격 (한 줄 정의)

> **"확정된 전제(컨셉·6팀·HI-Side Out·팀명) 위에서, 각 팀이 준비 중인 방향을 공유·조율하는 자리.
> 세부 확정은 8/16(컨텐츠 완성) 이후."**

### 2-2. 시간표 (총 90분)

```
오프닝            5분   확정 확인 + 3단 분류 공표 + 타임라인 앵커 + 진행 규칙
BLOCK 1 방향 논의 60분  컨텐츠(20) + 예산(20) + 교환·국제처(10) + 타임라인(10)
휴식              5분
BLOCK 2 마무리    20분  자유 건의(10) + Action Item·의존관계·마일스톤(10)
종료              10분  회의록 정리
```

> 💡 **타임라인팀 슬롯 신설 이유**: 타임라인팀은 회의 후 단 5일(8/14 타임라인 완성) 안에 산출물을 내야 하는 가장 타이트한 팀. 8/9 회의가 8/14 완성의 기점이므로, 여기서 컨텐츠팀 게임 방향을 수령하고 8/14 산출물 범위를 합의하는 유일한 조율 기회.

## 3. 문서별 수정안

### 3-1. `2차 회의 안건서 (진행용).md`

구조 재설계. 오프닝에 SSOT(3단 분류표·타임라인 앵커)를 세우고, 각 팀 발표 앞에 "오늘 모을 것(사전 공유됨)" 표시.

#### 오프닝 (5분)

**0-1. 회의 목적 한 줄** — "확정된 전제 위에서 방향을 잡는 자리"

**0-2. 확정 사항 확인 (1분 컷)** — 구체값 명시
- 행사명: HI-Side Out
- 팀명·컬러: Joy / Sadness / Anger / Disgust / Fear / Anxiety (감정 6색)
- (논의 아님, 확인만)

**0-3. ★ 3단 분류 공표 (신설, 핵심)** — 진행자가 소리 내어 읽고 화면에 띄움

| 단계 | 의미 | 오늘 해당 항목 |
|---|---|---|
| 🟢 확정 | 확인만, 논의 없음 | 컨셉·6팀·HI-Side Out·팀명·컬러 |
| 🟡 방향 | 옵션/철학만 잡음, 결정은 8/16+ | 게임 선종·점수철학·입장료·점심·단체티·구글폼 성별항목 |
| ⚪ 보류 | 듣고만, 상세는 8/16 | 게임 규칙·물품·시간·배치도·구글폼 상세·예산 시뮬 |

**0-4. ★ 전체 타임라인 앵커 (신설)** — 마스터지침 4-2 마일스톤을 한 장으로

```
지금(8/9)        8/16           8/26           9/19
방향 점검 ──→ 컨텐츠 완성 ──→ 최종기획안 ──→ Sports Day
   ↑              │              │
 오늘         세부 확정      임원진 인계
```

**0-5. 진행 규칙** — 시간 준수, 발표→Q&A 순, Q&A는 "방향"에 한정 (⚪ 디테일 질문은 "8/16에"로 미룸)

#### BLOCK 1: 방향 논의 (60분)

**1-A. 컨텐츠팀 (발표 8분 + Q&A 12분 = 20분)**

> 📌 **오늘 모을 것 (🟡 방향)** *(사전 안내문 공유됨)*
> - 게임 선종: 12종 중 "이 게임들로 가자"는 방향 (후보 확정, 상세규칙 X)
> - 점수 철학: 완만(A) vs 가파름(B) vs 등간격(C) — 어느 쪽이 좋을지 감만
>
> ⚪ **오늘 안 함**: 출전인원 상세, 물품 수량, 시간 설계, 캐릭터 매핑, 배치도

**1-B. 예산팀 (발표 8분 + Q&A 12분 = 20분)**

> 📌 **오늘 모을 것**
> - 🟢 팩트: 잔여 마리오 티 수량 (사전 조사 결과)
> - 🟡 방향: 입장료 / 점심 / 단체티 — 어느 옵션으로 갈지 감
>
> ⚪ **오늘 안 함**: 단가 시뮬레이션, 수량 확정, 예산안 총액

**1-C. 교환·국제처 (보고 5분 + 결정 5분 = 10분)** — *(기존 A4+A5 통합)*

> 📌 **오늘 모을 것**
> - ⚪ 보고: 구글폼 진행 상황 (8/20 완성 목표) / 국제처 컨택 사항 (임원진 경유)
> - 🟡 결정: **구글폼 성별 항목 최종 결정** (줄다리기·계주 성비용, 마스터지침 §6 🔴HIGH) — 8/20 구글폼 완성 전 마지막 집단 결정 기회

**1-D. 타임라인/인원관리팀 (방향 공유 10분)** — *신설*

> 📌 **오늘 모을 것**
> - 🟡 방향: 8/14 타임라인 완성 범위 합의 (25-2 타임라인 베이스 + 게임 소요시간 임시값)
> - 🟡 핸드오프: 컨텐츠팀 게임 12종 방향(1-A)을 수령해 8/14 베이스에 반영
> - ⚪ 보류: 상세 소요시간(8/16 컨텐츠 완성 후), 하클 배치표(8/17 인원조사 후)

#### BLOCK 2: 마무리 (20분)

**2-A. 자유 건의 (10분)** — 26-1 방식 차용

**2-B. Action Item + 의존관계 매핑 + 마일스톤 (10분)** — 신설: 방향→산출물 흐름도

```
게임 선종(🟡)  ──→ 8/16 컨텐츠 상세규칙 ──→ 예산 물품리스트
게임 선종(🟡)  ──→ 8/14 타임라인 베이스 (소요시간 임시값)  ← 신설
점수 철학(🟡)  ──→ 8/16 점수배분 확정   ──→ 교환 카드뉴스
입장료(🟡)    ──→ 동아리 보전 한도 확인 ──→ 8/26 예산안 확정
구글폼 성별(🟡)──→ 8/20 구글폼 완성       ← 신설
단체티(🟡)    ──→ 9/3 팀 배정 후 수량   ──→ 9/4 주문  ⚠️ 1일 버퍼 (크리티컬 패스)
```

> ⚠️ **9/3→9/4 크리티컬 패스**: 교환 팀 배정(9/3)이 하루만 늦어져도 단체티 주문(9/4)이 밀리고, 9/4 주문→9/19 행사 = 15일(탑앤탑 리드타임 감안 시 타이트). 플랜B: 팀 배정 지연 시 모객 수만 먼저 발주.

### 3-2. `2차 회의 안내문.md` (단톡 공지용)

### 3-3. `컨텐츠 초안 뼈대 (2차회의용).md`

> **주의**: 각 게임별 테이블의 디테일(출전인원·물품 수량·시간·캐릭터 매핑)은 **삭제하지 않고 남김**. 이 디테일은 8/16 컨텐츠 완성 작업의 씨앗이므로 보존한다. 대신 섹션 상단에 배지를 붙여 "회의에서는 여기까지 파고들지 않는다"는 신호만 추가.

```diff
## 1. 토너먼트 게임 4종 (초안)

+ > 📌 회의에서 다루는 것 (🟡 방향): 4종이 "어느 게임들인지" 후보 확인
```

**③ 배치도·물품 섹션에 "⚪ 전체 보류" 배지** — 사전 열람용으로만 정리.
